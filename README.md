## 🚀 Sobre o projeto

O **TechFlow** é um sistema web desenvolvido como projeto acadêmico de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de demonstrar uma solução para organização de chamados técnicos e gerenciamento de estoque de equipamentos e materiais de TI.

A aplicação simula o funcionamento de um departamento de suporte técnico dentro de uma empresa, conectando o usuário que solicita atendimento à equipe responsável pela gestão dos chamados e do estoque.

O projeto foi desenvolvido pensando em uma necessidade comum nas empresas: centralizar solicitações, acompanhar problemas técnicos e manter o controle dos materiais utilizados pela equipe de TI.

## 🎯 Qual problema o TechFlow busca resolver?

Em muitos ambientes corporativos, solicitações de suporte são realizadas informalmente, dificultando o acompanhamento dos atendimentos e a organização das prioridades.

O TechFlow propõe uma solução demonstrativa para:

- Centralizar a abertura de chamados técnicos.
- Organizar solicitações por equipamento e tipo de problema.
- Identificar a urgência de cada atendimento.
- Acompanhar o andamento e a resolução dos chamados.
- Controlar entradas e saídas de materiais.
- Consultar o histórico de movimentações do estoque.

## ⚙️ Principais funcionalidades

### 🧑‍💻 Portal do Usuário
- Identificação do solicitante.
- Seleção do equipamento com problema.
- Descrição detalhada da ocorrência.
- Definição do nível de urgência.
- Envio do chamado diretamente para a gestão.

### 📊 Painel Administrativo
- Visualização dos chamados recebidos.
- Indicadores de atendimento.
- Identificação visual das prioridades.
- Filtros por status.
- Ações para assumir e resolver chamados.
- Gráfico de movimentação do estoque.

### 📦 Controle de Estoque
- Cadastro e visualização de itens.
- Registro de entradas e saídas.
- Retirada de unidades.
- Indicadores de disponibilidade.
- Identificação de estoque baixo.
- Histórico de movimentações.
- Gráfico comparativo de entradas e saídas.

### 🔐 Controle de acesso
- Tela de login administrativo.
- Verificação de sessão.
- Proteção demonstrativa das páginas de gestão e estoque.

## ⚠️ Observações técnicas

O TechFlow é uma aplicação demonstrativa de front-end, sem servidor próprio. Os dados são armazenados no LocalStorage do navegador, não sendo compartilhados automaticamente entre diferentes dispositivos ou usuários.

A autenticação administrativa é apenas acadêmica e não oferece segurança adequada para produção. Uma implantação real exigiria autenticação e autorização validadas no servidor.
